# Reference: Original Phaser + React + TypeScript template

This is an untouched snapshot of the starter template the project was scaffolded
from (Phaser Studio's `template-react-ts`, running Phaser 4 / React 19 / Vite 6 /
TypeScript 5.7), kept here purely for reference.

The live project was cleaned up from this template — demo content (the moving-logo
scene, star-spawning buttons, placeholder "Game Over" flow, telemetry `log.js`,
and demo art assets) was removed, while the useful React↔Phaser bridge
(`PhaserGame.tsx`, `EventBus.ts`) was kept.

Nothing here is built or imported by the game. It is safe to delete this whole
folder at any time — the same files also live in git history.
